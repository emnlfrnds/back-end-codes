## 🛠️ Tech Stack Trabalhada

Neste repositório, os conceitos e projetos são desenvolvidos utilizando as seguintes tecnologias:

| Tecnologia | Descrição / Uso no Projeto |
| :--- | :--- |
| **JavaScript (ES6+)** | Linguagem principal para construção da lógica do lado do servidor. |
| **Node.js** | Ambiente de execução (*runtime*) que permite rodar o JavaScript fora do navegador. |
| **Express.js** | Framework web minimalista para criação de rotas, middlewares e APIs RESTful. |
